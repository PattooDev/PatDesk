# PatDesk

**PatDesk** est un bureau de widgets système pour **Deepin Linux**, basé sur **Eww (ElKowar's Wacky Widgets)**.

Le projet est développé pour créer un équivalent léger et personnalisable de Rainmeter sous Linux.

## ✨ Fonctionnalités actuelles

- 🕐 Horloge en temps réel
- 📅 Date
- 💻 Utilisation CPU
- 🧠 Utilisation RAM
- 🖥️ Positionnement sur le second écran
- 📌 Positionnement en haut à droite
- 🚀 Lancement automatique avec Deepin
- 🔄 Actualisation automatique des informations système

## 🖥️ Environnement

- Deepin 25
- Eww 0.6.0
- Bash
- Linux
